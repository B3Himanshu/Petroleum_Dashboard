================================================================================
HSRL FRONTEND — COMPLETE UI DESIGN SPECIFICATION (THREE MAIN PAGES)
================================================================================
This document lists every visible label, control, chart, table, modal, empty
state, colour, and persistence key for the production React UI under
`HSRL_ui/frontend/src`. Routes: `/dashboard`, `/comparison`, `/metrics-comparison`.

Canonical user-facing name for combined valet/coffee revenue: "Coffee & Valet"
(`constants/revenueLabels.js` — COFFEE_VALET_REVENUE_LABEL). Profit line label:
"Coffee & Valet profit" (COFFEE_VALET_PROFIT_LABEL). Pie/API may still return
"Valet Sales" or "Coffee & valet"; those map to the same purple slice colour.

================================================================================
SECTION A — GLOBAL SHELL (SHARED BY ALL THREE PAGES)
================================================================================

A.1 Page frame
  - Root: `min-h-screen bg-background relative`
  - Sidebar: fixed left, width 16rem (256px), `z-index` 1000, slides in/out with
    `translate-x` (500ms cubic-bezier). When open on large screens, main content
    uses `lg:ml-64`; when closed, `lg:ml-0`. Mobile: `ml-0` always.
  - Mobile overlay when sidebar open: full-screen `bg-black/50 z-40`, tap closes
    sidebar (lg:hidden only).

A.2 Floating menu (sidebar closed)
  - Fixed `top-4 left-4 z-[1001]`: rounded button, `bg-sidebar-bg`, border,
    shadow, `title="Show Sidebar"`, Menu icon.

A.3 Sidebar (`components/dashboard/Sidebar.jsx`)
  - Top row: Building2 icon in rounded-xl well; brand text "HIGHWAY STOPS RETAIL
    LIMITED" (text-xl font-bold); close button (X or Menu) with
    title "Hide Sidebar" / "Show Sidebar".
  - Section label: "MAIN MENU" (uppercase, tracking-wider, muted).
  - Nav items (full-width buttons, `sidebar-nav-item`, active state when path
    matches):
    * Sparkles icon — "Dashboard" → `/dashboard`
    * BarChart3 — "Metrics Comparison" → `/metrics-comparison`
    * GitCompare — "Site Comparison" → `/comparison`
  - Hidden behind `false &&`: "Location Dashboard" → `/location-dashboard` (not
    shown in production).
  - Footer border-t: "Sign out" with LogOut icon → logout + navigate `/login`.

A.4 Header (`components/dashboard/Header.jsx`)
  - Bar: `h-14 sm:h-16`, `bg-card`, `border-b border-border`,
    horizontal padding responsive.
  - Left: flex spacer (no sidebar toggle here — toggle lives in sidebar/floating
    control).
  - Right cluster:
    * When `showTotalSales` true: green primary pill — desktop "Total Sales:",
      mobile "Sales:", then £ + number + optional M/K unit (from absolute total).
    * When `onToggleRevenueInMillions` is a function: bordered panel with
      label "Show M" (hidden on xs) + Switch for millions vs exact formatting.
    * Border-l: circular avatar "HSRL" (gradient primary → chart-blue).

  Page-specific header wiring:
  - Dashboard (`LatestPetrol`): showTotalSales true, total from state; Show M
    switch wired.
  - Site Comparison: showTotalSales true; total = API all-sites sales (no date
    filter); no Show M switch passed.
  - Metrics Comparison: showTotalSales false; no revenue toggle.

A.5 Card / panel styling
  - Elevated panels: `chart-card` and/or shadcn `Card`.
  - Icons in titles often use `rounded-lg bg-primary/10` wells with primary-tinted
    lucide icons.
  - Frequent motion: `animate-slide-up`, chart scroll-in animations (~1.5s
    ease-out) via Intersection Observer where implemented.
