3. IMAGE LOADING CHAIN — SiteCard.jsx
================================================================================

SiteCard is the dashboard card showing each site's photo. Three-tier fallback:

  STEP 1: Local Photo (Primary)
  ├── Path: /sites/site-{siteId}.jpg
  ├── siteId from: site.siteId || site.id || 0
  ├── Only loads if siteId > 0
  ├── Attributes: loading="lazy", decoding="async", object-cover
  ├── On success: photo displayed
  └── On error: sets photoError=true → triggers Step 2

  STEP 2: Google Maps Embed (Fallback)
  ├── Trigger: localPhoto is null OR photoError is true
  ├── Gets coordinates: getSiteGeo(siteId) → { lat, lng }
  ├── Builds URL: buildGoogleMapsEmbedUrl(geo, zoom=17)
  ├── URL: https://www.google.com/maps?q={lat},{lng}&z=17&output=embed
  ├── Rendered as: <iframe> with border-0, loading="lazy"
  ├── No API key needed (basic embed)
  └── If no geo data → triggers Step 3

  STEP 3: MapPin Icon Placeholder (Final)
  ├── Trigger: no geo data found for this siteId
  ├── Rendered as: centered MapPin icon on bg-muted
  └── Appearance: w-8 h-8 text-muted-foreground opacity-40

  State reset: useEffect resets photoError to false when siteId changes.

4. IMAGE LOADING CHAIN — SitePhotoGallery.jsx
================================================================================

Used on Site Comparison page. Two-tier fallback (no Google Maps):

  STEP 1: Local Photo
  ├── buildSlides(siteId) returns: [{ src: "/sites/site-{siteId}.jpg", label: "Site Photo" }]
  ├── Single slide per site (carousel controls hidden when 1 slide)
  ├── On success: photo displayed in aspect-video container
  └── On error: adds index to imageErrors Set → triggers Step 2

  STEP 2: SVG Placeholder
  ├── Function: generatePlaceholder(siteName, 800, 600)
  ├── Generates: base64-encoded SVG data URI
  ├── SVG content:
  │     Background: dark gray (#1a1a1a)
  │     Text: white, centered, siteName
  │     Font: Arial, 24px (auto-scales for small containers)
  │     Escapes: &amp; &lt; &gt; for HTML safety
  ├── Format: data:image/svg+xml;base64,{encoded}
  └── Guard: only triggers once per index (prevents infinite loop)

  State on siteId change:
    - loading = true (100ms delay)
    - imageErrors = new Set()
    - currentIndex = 0

  Navigation (when multiple slides, future use):
    - Left/Right arrows: circular navigation
    - Thumbnails: h-20 w-28, active = primary border + ring
    - Counter badge: "X / Y" bottom center

6. URL BUILDER FUNCTIONS — siteGeo.js
================================================================================

6a) buildGoogleMapsEmbedUrl(geo, zoom = 17)
    CURRENTLY USED — SiteCard fallback
    No API key required.

    Input:  { lat: 52.487, lng: -1.894 }
    Output: https://www.google.com/maps?q=52.487,-1.894&z=17&output=embed

    Parameters:
      q      = latitude,longitude (center + marker)
      z      = zoom level (17 = street-level close-up)
      output = embed (renders in iframe)

6b) buildGoogleStaticMapUrl(geo, apiKey, options)
    NOT CURRENTLY USED — prepared for future
    Requires API key + Maps Static API enabled.

    Input:  { lat: 52.487, lng: -1.894 }, "AIza...", { zoom: 17 }
    Output: https://maps.googleapis.com/maps/api/staticmap?
              center=52.487,-1.894
              &zoom=17
              &size=640x360
              &maptype=satellite
              &scale=2
              &markers=color:red|52.487,-1.894
              &key=AIza...

    Parameters:
      center  = lat,lng
      zoom    = 17 (default)
      size    = 640x360 (default, high-res with scale=2)
      maptype = satellite (aerial view)
      scale   = 2 (retina/HiDPI)
      markers = red pin at center
      key     = Google API key

6c) buildGoogleStaticRoadMapUrl(geo, apiKey)
    NOT CURRENTLY USED
    Wrapper: calls buildGoogleStaticMapUrl with maptype=roadmap, zoom=16

6d) buildGoogleStreetViewUrl(geo, apiKey, options)
    NOT CURRENTLY USED
    Requires API key + Street View Static API enabled.

    Input:  { lat: 52.487, lng: -1.894 }, "AIza..."
    Output: https://maps.googleapis.com/maps/api/streetview?
              size=640x360
              &location=52.487,-1.894
              &fov=75
              &pitch=0
              &key=AIza...

    Parameters:
      size     = 640x360
      location = lat,lng
      fov      = 75° field of view
      pitch    = 0° (horizontal camera)
      key      = Google API key

    Note: if no Street View coverage at location, returns gray image.

7. INITIAL LANDING STATE — UK MAP (InitialLandingState.jsx)
================================================================================

Full-screen animated UK map shown on Location Dashboard.

7a) Google Maps Embed URL (hardcoded)

    !2d-5.152729...!3d52.752343...
    !4f13.1!2m1!1suk%20cities!5e0!3m2!1sen!2sin

    Decoded:
      Zoom:     ~3.5M units (wide UK view)
      Center:   lat 52.75, lng -5.15
      Tilt:     13.1° (satellite-like 3D)
      Search:   "uk cities"
      Language: English, region India

    No API key required (embed).

7b) UK Bounding Box
    west:  -9.0   (includes Ireland)
    south:  49.8   (English Channel)
    east:   2.8    (North Sea)
    north:  60.5   (Scottish Highlands)

7c) Pin Positioning — Web Mercator Projection

    Longitude → X%:
      lonNormalized = (lon - west) / (east - west)
      xPercent = lonNormalized * 100

    Latitude → Y% (Mercator):
      mercatorY(lat) = ln(tan(π/4 + lat_radians/2))
      latNormalized = (mercNorth - mercLat) / (mercNorth - mercSouth)
      yPercent = latNormalized * 100

    Final position (clamped 0–100%):
      top  = base.top + PIN_OFFSET.y (1.5%) + CITY_OFFSET.y
      left = base.left + PIN_OFFSET.x (1.0%) + CITY_OFFSET.x

    Global offset: { x: 1.0%, y: 1.5% } — compensates for embed framing.
    Per-city offsets: all { x: 0, y: 0 } currently (ready for fine-tuning).

7d) Zoom Animation
    Duration:    7 seconds (7000ms)
    Steps:       140 (50ms intervals)
    Easing:      cubic ease-out: 1 - (1 - progress)³
    Start scale: 9 (world-level zoom)
    End scale:   1.4 (UK focused)
    Transform:   scale(9 - progress * 7.6)
    Trigger:     dashboardVisible + mapLoaded, after 1200ms delay

8. CITY MAP — OpenStreetMap (CityMap.jsx)
================================================================================

Used on Location Dashboard when a specific site is selected.

8a) Map URL Construction
    Base:    https://www.openstreetmap.org/export/embed.html
    Params:  ?bbox={west},{south},{east},{north}&layer=mapnik

    "All sites" view:
      bbox=-8.0,49.8,2.0,61.0 (full UK)

    Specific city (e.g. Birmingham, delta=0.06):
      south = 52.4862 - 0.06 = 52.4262
      north = 52.4862 + 0.06 = 52.5462
      west  = -1.8904 - 0.06 = -1.9504
      east  = -1.8904 + 0.06 = -1.8304
      bbox=-1.9504,52.4262,-1.8304,52.5462

    No API key required (OpenStreetMap is free).

8b) Pin Overlay
    Position: always center (50%, 50%) — city is centered in bbox
    Visual:   red MapPin icon (w-10 h-10) + red pulse animation
    Offset:   transform translate(-50%, -100%) so pin point touches center
    Only shown: map loaded + specific city selected

8c) City Config (22 cities)
    Same cities as InitialLandingState but delta = 0.06 (tight zoom)
    except truro (0.08) and bury-st-edmunds (0.08)

8d) State Management
    On siteId change:
      - mapLoaded = false
      - mapKey incremented (forces iframe remount)
      - Fetches site data from sitesAPI.getById(siteId)
      - Extracts .city for bbox lookup

8e) Info Badge
    Bottom-left: "Selected Location" + city name
    Styling: bg-card/95 backdrop-blur-md rounded-lg

10. GOOGLE MAPS API KEY SETUP
================================================================================

Set in frontend/.env:
  VITE_GOOGLE_MAPS_API_KEY=your-key-here

Required APIs in Google Cloud Console:
  - Maps Static API     (satellite/road thumbnails)
  - Street View Static API (street-level photos)

Restriction: HTTP referrer → app URLs only.

Currently NOT needed for core UX:
  - Google embeds (SiteCard fallback, InitialLandingState) work without key
  - OpenStreetMap (CityMap) is free
  - Static Map / Street View functions exist but are not called

Only set the key if you want to activate:
  - buildGoogleStaticMapUrl()     → satellite thumbnails
  - buildGoogleStaticRoadMapUrl() → road map thumbnails
  - buildGoogleStreetViewUrl()    → street-level photos
